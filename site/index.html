Gestão de Clientes + Pipefy

API para cadastrar clientes de uma assessoria de investimentos, abrir cards no Pipefy via GraphQL e processar webhooks de atualização com idempotência e regra de prioridade por patrimônio.

Documentação da API Código no GitHub

Em números

3camadas: rotas, services e repositories
0eventos de webhook processados em dobro

Destaques de engenharia

Webhooks idempotentes

Cada evento do Pipefy tem um event_id único gravado no banco. Se o mesmo webhook chegar de novo, a API responde sem reprocessar o cliente.

Integração GraphQL

Monta as mutations createCard e updateCardField do Pipefy a partir dos dados do cliente, com os IDs de campo configuráveis por variável de ambiente.

Regra de negócio clara

Patrimônio a partir de R$ 200 mil vira prioridade_alta; abaixo disso, prioridade_normal. O cliente passa de "Aguardando Análise" para "Processado".

Arquitetura em camadas

Rotas FastAPI finas, regras nos services e acesso ao banco nos repositories, com validação de entrada por schemas Pydantic.

Segurança opcional

Com API_ACCESS_TOKEN configurado, os endpoints passam a exigir Authorization: Bearer; sem ele, a API roda livre para avaliação local.

Entrega

Imagem Docker com usuário sem root e GitHub Actions rodando os testes em duas versões do Python e o build da imagem.
