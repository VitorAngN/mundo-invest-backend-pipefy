## Como usar na defesa

Mostre rapidamente que o projeto foi pensado antes da implementacao:

- problema entendido;
- historias e criterios de aceite definidos;
- fluxo Scrum modelado;
- arquitetura separada em camadas;
- contratos de API definidos;
- banco modelado;
- testes planejados;
- seguranca pensada como evolucao sem desviar do MVP.
